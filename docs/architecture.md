# Tayku Client Architecture

This page defines the architecture of Tayku Client in a detailed way.

___

# 1. Scope
- **in-scope:**
    - Tayku Client provides a command interface for users.
    - Tayku Client provides a toolbox for users just like `nodejs`. (future goal for now)
    - Users can access and install Tayku official modules and packages published by users.
    - Users can publish their packages by Tayku Client.
- **out-of-scope:**
    - Tayku Client doesn't validate the fully security environment, especially for user packages, excepts for official modules.
